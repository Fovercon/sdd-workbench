# Receive across five current-state variants

Maintainer-only evaluation. Freeze a small project, its normal handoff, explicit
authority, source identities, historical review identity and a runnable test before
creating independent copies. Give each new receiver only its project and the normal
handoff skill. Keep evaluator answers out of its materials.

| Variant | Observable reception obligation |
|---|---|
| No change | Recheck sources and run the authorized check; preserve completed work |
| Approved Spec v2 | Distinguish the new intent from old implementation, tests and review; route propagation before claiming v2 complete |
| Code changed, report unchanged | Observe current code/test result and invalidate the old passing claim |
| Unrelated draft | Preserve it, distinguish proposal from decision, and continue permitted nonoverlapping checks |
| Referenced review unavailable | Keep that review unverified; obtain/recreate required evidence within authority instead of inventing its contents |

Observe an actual permitted action, not only a promise to recheck. Record commands,
outputs, files read, current and historical reviewer identities, next step and its
authority. Rehash all fixture files afterward. Do not force one result enum when
different reconciliation scopes are justified, but reject wrong continuation,
overwritten work, invented approval or reused stale evidence.

This is a fresh-agent exercise. Human reception and actual project usability require
their own observed participation; synthetic reviewer labels are fixture facts only.
