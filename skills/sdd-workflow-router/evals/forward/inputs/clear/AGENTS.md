# Fixture engineering rules
Use Python standard library only. Preserve notes.txt as user-owned work. No commits, pushes, network calls or external changes. Existing tests are observations, not business authority. The supplied request authorizes implementation, tests, local task evidence and local delivery. Routine technical choices are delegated. If a material user decision is missing, save a concrete question in questions-needed.md and stop dependent work; do not ask the real user through tools. Use project/evidence locations of your choice, proportional to this small task. Review may be self-review here, but must not be called independent. Keep a chronological trace.md of stage actions, commands, results, repairs and stopping reason. Do not read outside this fixture and its sibling skills directory.
