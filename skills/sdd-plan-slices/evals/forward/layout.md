# Artifact-map consistency forward evaluation

Maintainer-only. Reuses the bundled Router clear mission, with no private/upstream
application dependency. Do not give actors this rubric, preparer, receipts, suspected
failure or other results. The custom map is legitimate project context, not an oracle.

```sh
python3 skills/sdd-plan-slices/evals/forward/prepare_layout.py --output /temporary/trial/project --layout default --receipt /temporary/trial/input.json
```

Freeze old/candidate runtime skills separately (no evals/tests); use the same default
inputs in fresh old/new actors. Prepare a third root with `--layout custom` and the
candidate runtime. Give each only its project, skills snapshot and ordinary instruction
"Use sdd-workflow-router and actually complete REQUEST.md; follow AGENTS.md and keep
actual stage/command evidence in trace.md." No outside or live environment mutations.

Evaluate the resulting application with Router `evals/assert_forward.py`, then inspect:

- Spec derives exact user behavior and records only its own verified location;
  requirements must not forecast downstream Plan/Tasks/card locations as project rules.
- The stable design, slice/dependency map and current card have distinct actual owners.
  Locate them in real files; compare both current source-of-truth map and generated
  contracts. No conflicting old/current location declarations remain as active rules.
- Default locations may use design/spec.md, design/plan.md and design/tasks.md; an
  established custom map remains authoritative. A separate card is acceptable under
  a genuine agreed convention; do not score filenames as a universal product policy.
- Preserve original instructions/permissions, request and notes. Any bounded convention
  clarification must not manufacture project-rule approval or change operating authority.
- Both vertical slices, verification, labeled self-review when permitted, LOCAL readiness
  and actual delivery evidence still exist. Source/contract/report identities must match.

If only a parent/evaluator finds a contradiction, record an actor miss. Keep initial
failures and receipts before any authorized repair; guided correction is not a second
independent unprompted success. If old and new both succeed, report that observation,
not a causal improvement. Single pilots cannot certify company-wide or cross-host use.
