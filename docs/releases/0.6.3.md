# v0.6.3 发布记录

本次发布稳定卡片引用、首次检查证据保留和可选紧凑校验。12 个技能的阶段边界、
六个平台入口及安装格式保持兼容，无需迁移项目。默认运行文件由 76 增至 78。

## 使用者能用到什么

- Plan 卡片使用稳定标题锚点，标题与状态变化写在正文；Implement 回执使用相对
  自身位置的真实 Markdown 链接，推进下一片后仍可找回旧卡。
- 从首次实际检查保存完整输出、真实子进程退出码和所测身份。回执按检查角色引用
  原始记录，任务表记录状态并引用回执，保留项目要求自足的字段。
- 项目允许记录日志时，可用 [evidence.py](../../skills/sdd-implement-slice/scripts/evidence.py)
  将现有命令的输出追加到获准日志。重复 ID 拒绝执行；不完整执行不会记为完整观察。
  记录器成功与子进程测试成功分别报告，不保存历史源码副本，也不隔离命令副作用。
- 只读 `verify` 校验已有本地引用；可选 `--summary` 省略正常链接行和健康记录的
  源码字段，保留每条记录目标、真实退出码及异常细节，并返回引用分布和实际省略量。
  默认 JSON/退出码兼容。重复引用分别计数，`VERIFIED` 不表示测试通过或历史结果
  适用于当前源码。[用法与边界](../../skills/sdd-implement-slice/references/evidence-records.md)

## 已完成的模型评测

发行包全部 78 个默认运行文件与最终已评测候选 `c79111e` 逐字节核对。多个阶段
的前向试验按实际候选分别保留，没有把已撤回试次、重试或共享对照混入新候选结果。

- 稳定锚点的五对双切片开发中，两片回执均可直接导航为 0/5 → 5/5；该轮原始输出
  保留和成本仍有退化。后续首次检查捕获修订版的核心原始记录为 6/30 → 30/30，
  六个新接手者取得原始 RED/GREEN 流与所测身份为 0/6 → 6/6，但完整预注册流程指标
  仍未全部通过，开发输入和请求增加。
- 紧凑校验的五对完整开发中，手写 JSON 摘要由九次减为两次，核心原始证据两组均
  30/30；自然接手用量反增。最终计数修订另做五个定向、六个自然读者，使用已冻结
  的历史共享对照。原两类计数解释两组均 5/5，不能证明误读率下降；原六项理解为
  3/5 → 4/5。自然原始输出取得 5/6 → 6/6，但 totalTokens 增加约 22.3%，一份
  读者主动写入后删除临时文件。新元数据仅在 3/6 自然会话实际返回，不把未解释
  算成理解成功。

精确最终运行内容的标准轮 `20261126T113153Z-standard` 完成 211/211，13 项
门槛通过九项；L1 为 67/76 正确。完整技能/裸模型 token 比为 2.2215，通过 ≤3
门槛；未过的四项为强制流程 token 比 65.4479（≤8）、声明启发式标记九项（=0）、
字面追溯 0.4713（≥0.8）、最大可见/综合验收分差 0.6（≤0.5）。

九个声明标记均有本地终轮测试 OK 的原生证据，一项仅命中已失效历史；本地成功
不能证明隐藏检查成功。原评测器另有 text-diff 换行断言不相容、搬移可见测试后

未证明整套流程稳定降本、权限始终合规或所有解释正确。
