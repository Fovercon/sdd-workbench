- 宽屏改为左侧流程导航，统一使用本地 SVG 线性图标和单一靛紫强调色；内容区集中阅读。
- 项目标题、目标、范围、计数与下一步使用不同层级，压缩重复的阶段标题和说明；统一留白、边框、圆角和字体。
- 详情按需展开，支持关闭按钮、Escape 和焦点返回；来源仍能直接打开，深链和浏览器历史保留。
- 长项目说明可展开/收起，原始文本保持完整；无 JavaScript 时全部可读。
- 任务列用状态标记与轻量卡片区分，具体验收和阻塞保持可见。
- 验收矩阵先显示实际阻塞及未覆盖验项，完整缺口可展开；来源失效/未执行/失败仍会阻止覆盖通过。
- 窄屏使用可横向滚动的流程导航，切换与刷新后把当前阶段带入可见区域；宽表有滑动提示，页面本身不横向溢出。
