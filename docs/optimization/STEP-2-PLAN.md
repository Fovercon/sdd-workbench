接续第一步候选与其原始证据，首批用户已确认为研发工程师。

## 本轮可观察目标

| ID | 行为 | 证据 |
|---|---|---|
| D-1 | 一条只读命令列出六平台原生/共享根中的套件副本、缺失、不同内容和共享链接 | 临时 home、不同版本/编辑/别名/断链/损坏回执用例 |
| D-2 | 检出 Python 安装器的未恢复事务与已记录目录的编辑；给出保留工作后的人工下一步 | 真实临时安装与故障状态；不调用安装/恢复/客户端 |
| D-3 | 客户端/Node/Git/浏览器只报告路径观察，执行/发现/权限/模型行为保持未验证 | 可注入 PATH 探测、无副作用 CLI 和假客户端不可执行证明 |
| D-4 | 无回执的共享/原生安装仍可检查；相同真实目录的符号链接不误报独立重复安装 | 真实符号链接与不同物理副本用例；不能从字节相同推断版本/所有权 |
| L-1 | Spec 不预先决定下游卡片位置；Plan核对实际项目映射，修正自己产生的冲突声明 | 默认/已有自定义布局的独立实际 actor，保留旧轮漏检 |
| E-1 | 研发任务矩阵分别记录资产、安装、发现、实际任务和真人试用证据 | 已有记录可追溯；未知组合标未执行，不借测试数量认证 |
| V-1 本轮发现后追加 | 广义异常合同不能因既有绿色测试被误判覆盖；错误异常仍是失败 | 保留 change 初轮与父级探针盲区，扩展输入类，强化 Converge Review 后相同输入新会话复跑 |

实现边界：新增 stdlib doctor，不改安装事务/所有权机制。读取的额外目录仅限选定目标和
显式共享根；不读取宿主账号/模型配置，不联网，不运行 PATH 中的脚本，不产生自动修复。
`--dest` 的单目标检查只检查给出的目录；`--home` 沿用安装器的隔离语义。
诊断器不是宿主完整发现器，插件缓存和自定义搜索路径须显式给出，Hermes/ZCode 的共享
自动发现也不能从公共目录存在直接推断。结果只覆盖本次可见文件，不构成模型行为认证。

布局方法改动属于 IMPLEMENT 层的合同一致性修正：既有“Spec/Plan/Tasks 各自归属”保持，
修复第一步实测中出现的前置布局臆定与追加冲突。保留原 RUN 和审批边界，不新增必填清单。
所有方法演练用新隔离目录，保留权限、用户 notes、原始失败与旧/新快照；无 live skills 写入。

追加范围依据：实际 change 演练声称“any unknown state -> ValueError”已验证，但 set
成员检查对列表/字典抛 TypeError。初版父级探针也只测 unknown 字符串，曾漏掉此问题。
这是明确合同的验证覆盖错误，不是新增业务校验需求。只补 Converge Review 的合同输入类
核对规则与对应回归，不批量重写其他技能；保留首次失败，不以指导修复冒充独立成功。

本轮不选择公司许可、模型供应商、安全策略或真实试点人数。代表性真实项目/人员仍需
公司提供；先交付可复跑的工程基线和诚实的缺口矩阵。
