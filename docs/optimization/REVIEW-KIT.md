# 供独立 agents 与专家使用的审查包

目标是发现真实任务失败和成本，意见人数不是证据。先独立使用，再阅读作者的不足清单，
减少作者结论对 reviewer 的锚定。若已读过作者结论，照实记录，不声称盲审。

## 固定被审对象

本轮比较基线为 v0.2.1 / `6de58e3b028c8252c2b52ee7fd49a404b4def7da`。
当前合并候选位于 `codex/enterprise-readiness-step1`，包含后续优化，当前累计版本按 0.3.0 整理；远端发布状态另见[准备记录](../releases/0.3.0.md)。
每一步结果中的输入/技能快照和工作树清单只覆盖当时内容，不能自动覆盖后续工作树。
转交当前候选时重新冻结并记录：
记录 `git rev-parse HEAD`、`git diff --binary HEAD` 的 SHA256 和实际技能文件哈希。
Git diff 不包含未跟踪文件；还必须列出 `git ls-files --others --exclude-standard` 中的
候选文件及 SHA256，或提供包含所有候选文件的快照/本地审查提交。不要漏掉新增指南、
fixtures 与测试。完整工作树清单可保存在本地忽略的评测档案，避免清单自引用。
branch 名或 plugin.json 中的版本号不能独立标识候选内容。

请复制到新的临时工作区或独立 checkout，避免多个 agent 同时修改同一份项目。
方法 actor 只拿 runtime skill 及原始任务输入，不拿评测 rubric、准备器或另一个 actor 的结果。
公开 QUICKSTART 属于产品材料，可以用于新人试用；作者评估和评分规则应在独立初判后阅读。

## 可转交的普通任务说明

> 用这份固定版本的 SDD Workbench，在隔离项目里实际完成给定请求。只使用给出的项目资料，
> 不猜业务规则；遵循项目权限，保留用户文件，不做未授权提交/发布。记录你实际读了什么、
> 做了什么、卡在什么位置，以及最后产物和验证。不要只说明“会怎么做”。

挑选真实代表任务而非只挑作者样例：

- 清楚的小改动或已有 bug：是否实际完成，是否产生不必要的 Spec/Plan/看板？
- 一个含不确定输入的新功能：问题是否具体，是否在缺语义时编造实现？
- 只问状态：是否诚实说出缺证据且保持只读？
- 已有批准合同被修订或中断恢复：是否核对旧身份、使受影响证据失效并保护原文件？
- 明确保留设计批准：是否准备具体审查对象后停止，而非自批或重复索取已给授权？

同题比较需固定代码/数据/合同、任务授权、模型设置、宿主权限和结束条件；新上下文独立运行。
出现环境差异、已见过答案或 reviewer 干预时保留记录。不要为了让套件过关删除失败样本。

首批试点人群已由用户确认为研发工程师。优先选择局部修复、存量小功能、需求变更、
评审交接和中断续接；分别记录首次使用本套件与熟悉本套件的研发人员表现。真实人员的
试用与 agent 方法演练分开，不能把 agent 扮演新人的输出称为真人上手结果。具体组合见
[计划中的试点优先级](PLAN.md#已确认的首批人群与验证优先级)。

## 最小反馈记录

多人/跨版本正式审查可以使用[本地反馈校验工具](../REVIEW-FEEDBACK.md)，固定候选指纹、
生成草稿并关联实际证据与后续复验。工具不认证身份、不执行报告命令、不代 owner 关闭问题；
普通小任务仍可直接使用下面的文字记录，无需为工具制造额外文档。

```text
被审基线 / 候选 diff 身份：
Reviewer 身份与角色：人工 / 独立 agent / 实施者自检（是否已读作者结论）：
客户端 / 模型与设置 / OS / 允许的工具：
任务原文、输入与它们的指纹：
复现步骤、命令、实际退出/输出/产物位置：
期望行为及其来源（用户/项目规则/合同）：
观察事实；另列原因推测：
后果及建议严重度 P0/P1/P2/P3：
是否改了输入/给了提示/人工救场；实际耗时或可得 Token；未取得的数据：
保护文件、未授权动作及最终任务是否完成：
最小修复建议；复验方式与保留证据：
```

不把凭据、公司私有代码或真实业务数据贴到公开 issue。公司敏感材料的保管位置由 owner 指定。
发现冲突时，先看被审版本/任务/合同是否一致，再检查可复现事实；不可按 agent 投票覆盖产品
决策。归并相同原因后保留每个报告来源，标明待复现/已复现/修复待验/已复验/不采纳及理由。
P0/P1 优先闭环，但所有意见不自动触发规范修改或授权发布。重要修复应由非实施者复验。

此包没有替其他 agents/专家生成意见、代其打分或批准推广。实际结果和证据限制需单独记录。
