本轮不把历史待办全部改为完成：真人首次使用、其他宿主完整业务试点、公司政策和同条件框架比较仍需要实际参与者/环境；设计经济性等方法提案不与发行整理混做。后续按证据逐项推进。可独立复现的评测输入随相应技能保留，原始本机运行记录不进发行包。
