1. 项目规则分别展示约束和命令；命令按原文显示，标明是否执行及实际结果，不提供自动执行。

4. 交付收尾分别展示交付物、使用步骤、限制、接续和恢复方法；准备好文件与实际交付分开，缺少交付记录时明确提示。

6. 延续顶部导航、有限配色、明确字号与字重；键盘、深链、窄屏、无JS及原来源阅读可用。
